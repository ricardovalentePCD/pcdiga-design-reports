Issues por versão — o que ficou por resolver
✓ V1 + V2
Banner compacto + chips horizontais — resolvido desde V1

Os dois maiores problemas de espaço do Live foram resolvidos em V1 e mantidos em V2: banner −64px e categorias −72px. Total de +136px above-fold. O produto entra no viewport muito mais cedo.

✦ UX Pro Max: layout-responsive · touch-target-size
✓ V2 apenas
Identidade de campanha no bloco — resolvido em V2

Em V1 o bloco de campanha ficava sobre fundo escuro neutro, sem ligação à cor da campanha. Em V2, fundo laranja sólido cria identidade imediata. O utilizador reconhece o contexto de campanha sem ler o texto. Era o maior issue de V1.

✦ UX Pro Max: consistency · style-match ecommerce
✓ V2 apenas
"VER MAIS" redundante — eliminado em V2

Live e V1 tinham múltiplos CTAs a competir no mesmo bloco. V2 eliminou o "VER MAIS" e mantém apenas "VER CAMPANHA" como acção principal, integrado no bloco laranja.

✦ UX Pro Max: CTAs — acção principal única por bloco
PRIORITÁRIO
Peek do 3.º card — pendente em todas as versões

Live, V1 e V2 — nenhuma versão tem peek do 3.º produto. Os cards preenchem 100% da largura, não sinalizando ao utilizador que existe mais conteúdo em scroll. Este é o próximo passo imediato para V2.

💡 Card width: 50% → 44vw. O 3.º card aparece com ~8vw à direita. Fade gradient no container.
✦ UX Pro Max: horizontal-scroll — peek obrigatório
MÉDIO
SKU nos cards — pendente em todas as versões

A referência SKU (82KU01YQPG) está visível com peso igual a nome e preço em Live, V1 e V2. Uma linha de CSS resolve.

💡 @media (max-width: 768px) { .product-sku { display: none; } }
✦ UX Pro Max: style-match e-commerce — hierarquia nome → preço → stock
Veredicto final
✅ V2 é a versão correta — 2 fixes rápidos para potencial máximo

A evolução das 3 versões é coerente e cada iteração resolve problemas reais. V1 recuperou 136px above-fold — o maior salto único. V2 completou o trabalho ao resolver a identidade visual do campaign block com o fundo laranja, criando consistência de cor banner → bloco → cards.

V2 está pronta para produção. Os 2 fixes restantes — peek do 3.º card e remoção do SKU mobile — são ambos de CSS e fazem o score subir de 8.5 para próximo de 9.5.
