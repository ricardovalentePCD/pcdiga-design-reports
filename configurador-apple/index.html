Pontos de Atenção e Recomendações

UX-01 — Stepper não é clicável — navegação linear obrigatória HIGH

Barra de progresso (stepper)

Com 11 passos de configuração, obrigar o utilizador a usar apenas os botões Anterior/Próximo é ineficiente. Se errar na cor (passo 2) e estiver no Software (passo 10), precisa de retroceder 8 vezes.

Recomendação: Tornar os passos já completados clicáveis no stepper, permitindo navegação direta. Passos futuros podem permanecer bloqueados ou permitir saltos com valores default.
UX-02 — Falta indicador numérico de progresso MEDIUM

Stepper / Header da secção

O utilizador não sabe facilmente em que passo está (é o 2 de quantos?). Contar ícones visualmente é cognitivamente exigente, especialmente quando alguns saem do viewport.

Recomendação: Adicionar indicador textual 'Passo 2 de 11' ou uma barra de progresso percentual complementar ao stepper.
UX-03 — V2 perde acessibilidade ao usar só cor como indicador de estado MEDIUM

Stepper — passos completos (V2)

Na V2, a única diferença entre um passo completo e um futuro é a cor verde vs cinzento. Utilizadores com deficiência visual cromática (≈8% homens) podem não distinguir os estados.

Recomendação: Combinar a abordagem de ambas as versões: manter o ícone da categoria (V2) mas adicionar um pequeno badge de checkmark ou um anel/círculo verde à volta do ícone. Assim usa-se forma + cor + contexto.
UX-04 — Bloco de texto descritivo compete com as opções de configuração LOW

Zona inferior do ecrã (V1A/V2A)

O parágrafo descritivo do produto ('O design é composto por um chassi...') ocupa espaço visual significativo e desvia atenção da tarefa principal: configurar. Esta informação é mais relevante numa página de produto, não durante a configuração.

Recomendação: Mover este texto para um accordion/expandível 'Saber mais sobre este produto' ou removê-lo da vista de configuração. Isto liberta espaço para as opções ficarem mais respiráveis.
UX-05 — Falta feedback visual de seleção nas opções LOW

Cards de opções (Cor, Software, etc.)

Ao selecionar uma opção (ex: 'Preto Sideral'), o card fica com um estilo ligeiramente diferente mas falta uma transição/animação que confirme a ação. O utilizador pode não ter a certeza de que a sua escolha foi registada.

Recomendação: Adicionar uma micro-animação (scale + checkmark) ao selecionar uma opção, e garantir que a opção selecionada tem um contraste forte (borda laranja ou background diferenciado).
UX-06 — Preço total pouco destacado LOW

Painel direito — Total

O preço total (1949,00€ / 3040,71€) está no fundo do painel direito sem grande destaque visual. Para uma decisão de compra deste valor, o preço deveria ser mais proeminente.

Recomendação: Aumentar o tamanho do preço total, possivelmente com um fundo diferenciado ou fixá-lo no fundo do painel para estar sempre visível durante o scroll.
OK-01 — Estrutura geral do configurador é clara e funcional OK

Layout geral

A divisão em categoria mãe → stepper → opções → resumo lateral segue um padrão de configuração bem estabelecido. A hierarquia visual é boa e o fluxo é intuitivo.

Recomendação: Manter esta estrutura — é um bom alicerce.
OK-02 — Resumo lateral com custos incrementais é excelente OK

Painel direito

Mostrar a lista de escolhas feitas com os custos extras (+ 250,00€, + 756,71€) dá transparência total ao utilizador sobre o impacto de cada decisão no preço final. Muito bem executado.

Recomendação: Manter e considerar adicionar a possibilidade de clicar num item do resumo para voltar a esse passo diretamente.
OK-03 — Cards de produto no topo com preço 'Desde' são informativos OK

Seletor de categoria mãe

Os cards horizontais com imagem, nome e preço base permitem comparação rápida entre modelos antes de começar a configuração.

Recomendação: Manter. Considerar tooltip ou hover com specs principais para comparação mais rápida.

A estrutura geral do configurador é sólida e bem pensada. Os ajustes prioritários são tornar o stepper clicável e adicionar um indicador numérico de progresso.

O que está muito bem feito
  • Estrutura clara: categoria mãe → stepper → opções → resumo. Padrão de configuração bem implementado.
  • Resumo lateral com custos incrementais — transparência exemplar no impacto de preço.
  • V2 melhora o reconhecimento contextual mantendo os ícones categóricos (vantagem sobre checkmarks genéricos).
  • Dark theme PCDIGA consistente e profissional.
  • Cards de seleção de modelo com preço base permitem comparação imediata.
O que merece atenção
  • Stepper deve ser clicável para navegação direta — crítico num fluxo de 11 passos.
  • Adicionar indicador numérico de progresso ('Passo X de Y').
  • V2 precisa de indicador dual (forma + cor) para acessibilidade — combinar ícone categórico com mini-checkmark.
  • Mover texto descritivo para expandível — liberta espaço para as opções.
  • Considerar preço total sticky/fixed no painel direito para estar sempre visível.
